### Entrada y Salida del Usuario

Para capturar las teclas del usuario usaremos el comando *read* y para la salida usaremos *echo*

Ejemplo:

```bash
read -p "Escribe un numero: " numero # Entrada
echo "El numero es: $numero" #Salida
```
