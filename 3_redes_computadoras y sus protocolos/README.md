# Redes de Computadoras y Protocolos
Expandido para cubrir desde la conmutación local hasta el enrutamiento global.

- Parte 1: Conceptos Basicos.

- Parte 2: Diseño de Redes Jerarquico (Direcciones MAC, Switches, ARP)

- Parte 3: IPv4 a fondo: Clases, Subnetting, VLSM y CIDR (Matemática de redes).

- Parte 4: El futuro ineludible: IPv6 (Estructura, SLAAC y diferencias con IPv4).

- Parte 5: Enrutamiento (Routing): Cómo viajan los paquetes (Rutas estáticas y NAT).

- Parte 6: Protocolos de enrutamiento dinámico (BGP, OSPF) explicados simple.

- Parte 7: Capa 4: TCP (El Handshake de 3 vías y control de flujo) vs. UDP.

- Parte 8: DNS en profundidad: Registros (A, AAAA, MX, TXT) y resolución iterativa/recursiva.

- Parte 9: DHCP: El proceso DORA y la asignación dinámica de IPs.

- Parte 10: VLANs y Trunking (802.1Q): Segmentación de redes lógicas.

- Parte 11: Criptografía en red: Hashes (MD5, SHA) y Cifrado (AES, RSA).

- Parte 12: El protocolo TLS/SSL: Cómo funciona el Handshake criptográfico de HTTPS.

- Parte 13: VPNs y Túneles: IPsec, OpenVPN y WireGuard.

- Parte 14: Análisis de Tráfico 1: Filtros avanzados en Wireshark.

- Parte 15: Análisis de Tráfico 2: Extracción de archivos y credenciales desde PCAPs.

- Parte 16: Herramientas de línea de comandos para redes (Tcpdump y Tshark).
